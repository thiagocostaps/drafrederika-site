# Site — Dra. Frederika Cartagena (Ortodontia e Estética)

Site estático publicado no GitHub Pages em **https://www.drafrederika.com.br**.

- `index.html` — página única (textos, contatos, clínicas)
- `assets/css/style.css`, `assets/js/main.js` — visual e menu do celular
- `assets/img/` — imagens otimizadas (WebP). Casos publicados com autorização por escrito dos pacientes (Resolução CFO-196/2019)
- `CNAME` — domínio do site

Para mudar um texto: edite `index.html` e envie para a branch `main`; o GitHub Pages publica sozinho.
O sistema de atendimentos é outro projeto (privado), em app.drafrederika.com.br.
